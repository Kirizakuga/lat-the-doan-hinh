# Lật thẻ đoán hình

A 3-round quiz game for class: 9 numbered tiles hide a secret picture. Pick a tile, read the question, press "Xem đáp án" to show the answer, then mark it Đúng (the tile flips away) or Sai (the tile greys out).

- Edit the questions in the `ROUNDS` list near the bottom of `index.html`.
- Add the secret pictures to `images/` (see `images/README.md`), or upload one in the page.
- Progress is saved in the browser. "Bắt đầu lại vòng này" resets the current round.
